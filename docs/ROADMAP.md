# Roadmap

Offline-first features now include manual URL/text jobs, favorites, editable local drafts/PDFs, four portable AI artifact types, preview/confirm imports, canonical URL deduplication and private exports/backups. Integrated providers are optional.

Current preview includes resumable local profile drafts, cancellable feed discovery, configured Greenhouse/Lever/Ashby boards, system dark appearance and an isolated French static website. Release candidates have Sparkle/signing/notarization/DMG tooling; no public acceptance is implied.

Existing workflows: local onboarding, provider connection, public-feed discovery, explicit offer feedback, factual dossier preparation and manual submission tracking.

Release priorities:

- Verify real-account sign-in/inference and current provider distribution requirements.
- Execute the protected release workflow with Apple and Sparkle credentials; verify nested browser execution, signed updates, Gatekeeper and recovery on clean Macs. See RELEASING.md.
- Reorder the onboarding into the full welcome → profile → CV → preferences → provider journey; validate structured CV extraction before adopting candidate facts.
- Extend the explicit salary/remote exclusion control with verified location/salary normalization, side-by-side comparisons and richer shortlist organization. Current ranking remains conservative and local.
- Verify live employer-board responses and expand beyond the first bounded page only when coverage justifies it.
- Improve form inspection and matching with reproducible, fictional fixtures.
- Improve keyboard access, responsive layouts and language coverage.

The project does not promise a release date or automatic submission. Candidate data protection, factual answers and clear provider costs take precedence over expanding the feature list.
