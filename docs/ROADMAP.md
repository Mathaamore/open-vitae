# Roadmap

Current preview: local onboarding, provider connection, public-feed discovery, explicit offer feedback, factual dossier preparation and manual submission tracking.

Release priorities:

- Verify real-account sign-in/inference and current provider distribution requirements.
- Sign and notarize the Mac installer; document upgrades and recovery.
- Improve form inspection and matching with reproducible, fictional fixtures.
- Improve keyboard access, responsive layouts and language coverage.

The project does not promise a release date or automatic submission. Candidate data protection, factual answers and clear provider costs take precedence over expanding the feature list.
